# Collective Coffee House

A premium, frontend-only React website concept for Collective Coffee House, Nagpur.

## Stack
- React + Vite
- Bootstrap 5 / React Bootstrap
- Framer Motion
- Lucide React
- CSS

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

## Before presenting to the business
This is a visual demo. Menu items, prices, hours, testimonials and contact links are illustrative or require owner confirmation. Replace them with verified business information before launch.

Photography is loaded from Unsplash image URLs. For a final client deployment, download properly licensed selected images and serve them from `public/images`.
